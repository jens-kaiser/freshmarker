= Release Notes

== Release 1.6.9 (planned 2024-12-XX)

=== Improvements

- support range variables in dynamic key expressions
- add `TemplateBuilder#withClock`

=== Bugfixes

- remove state from model ranges

== Release 1.6.8 (2024-11-20)

=== Improvements

- add resource bundle parameter to `i18n` built-in
- add `registerBuiltInVariableProviders` for custom built-in variables

== Release 1.6.7 (2024-11-15)

=== Improvements

- add `Configuration#registerFormatter` to customize temporal and number formatting

=== Experimental

- add `i18n` built-in

=== Breaking Changes

- macro and variable names may only be identifiers and no longer string literals

== Release 1.6.6 (planned 2024-11-02)

=== Improvements

- add `filter` part to the list directive
- add `limit` part to the list directive
- add brick directive

== Release 1.6.5 (2024-10-29)

=== Bugfixes

- fix chained exists operator

== Release 1.6.4 (2024-10-26)

=== Improvements

- add `AtomicInteger` and `AtomLong` support
- add unicode multiply `×` and divide `÷` operator
- add exclusive right limited range `..<` and length limited range  `..*` operator
- expand slicing to ranges
- add ranges built-ins `lower`, `upper`, `size`, `reverse`, `join`
- add inverse slicing

=== Deprecated

- remove `BaseReflectionsMap`, `TemplateMapReflectionsProvider`

=== Breaking Changes

- remove `FeatureFlag`
- empty user directives body is always `ConstantFragment.EMPTY` and never `null`

== Release 1.6.3 (2024-10-16)

=== Improvements

- add operator overloading

=== Experimental

- add `+` and `-` operators for `TemplateLocalDate` and `TemplatePeriod`
- add `<`, `+<=+`, `>`, `>=`, `≤` and `≥` operators for `TemplateVersion`

== Release 1.6.2 (2024-10-13)

=== Improvements

- add `∃` operator

=== Breaking Changes

- move `∨`, `∧` from conditional to logical operators

== Release 1.6.1 (2024-10-11)

=== Improvements

- add date built-ins `since` and `until`
- add duration built-ins `c` and `h`
- add duration built-ins `years`, `months` and `days`
- add `⊻`, `¬`, `≠`, `≤`, `≥`, `∨`, `∧` operators

=== Breaking Changes

- remove `lt`, `gt`, `lte`, `gte` operators

== Release 1.6.0 (2024-10-03)

=== Improvements

- add number built-ins `min` and `max`
- add number built-ins `big_integer` und `big_decimal`
- add alternative name `escape` for built-in `esc`
- add alternative names `no_esc` and `no_escape` for built-in `noEsc`

=== Breaking Changes

- `ftl` header removed
- `esc` without a parameter generates a process exception

== Release 1.5.3 (2024-09-30)

=== Improvements

- `BigInteger` and `BigDecimal` support

== Release 1.5.2 (2024-09-29)

=== Improvements

- add `TemplateBuilder#withOutputFormat`

== Release 1.5.1 (2024-09-27)

=== Improvements

- sequence built-in `join`

== Release 1.5.0 (2024-09-09)

=== Breaking Changes

- introduce `TemplateBuilder`

== Release 1.4.6 (2024-09-08)

=== Improvements

- add string built-in `slugify`
- add number, boolean and date built-ins `h` (_human language_)
