= Release Notes

== Release 1.9.1 (2025-06-XX planned)

=== Improvements

- add number built-in `clamp`
- unfold ist directives on partial reduction
- add `ReductionFeature.UNFOLD_LIST` feature, to activate unfolding
- add `ReductionFeature.MERGE_CONSTANT_FRAGMENTS` feature, to activate merging of constant fragments
- add `Character` support
- add character built-ins `is_digit`, `is_letter`, `is_whitespace`, `is_upper_case`, `is_lower_case`, `upper_case`, `lower_case`, `is_alphabetic`
- add experimental character built-ins `is_emoji`, `unicode_block`
- add number built-in `unicode`
- add `SecurityFeature.MODEL_SECURITY` feature, to deactivate model security

== Release 1.9.0 (2025-06-01)

=== Improvements

- add `AtomicBoolean` support
- add `OffsetDateTime` support
- add string built-ins `center_pad`
- add type checking built_ins `is_temporal`
- add string built-ins `mask` and `mask_full`
- add temporal `supports` built-in
- change variable context mechanism.
- add `VariableContextFeature.ALL_BLOCKS` feature, to allow variable scopes to `user` and `brick` directives
- add `assign` directive
- add multiple variable support for `var`, `set` and `assign` directives

== Release 1.8.1 (2025-05-14)

=== Improvements

- add string built-ins `left_pad` and `right_pad`
- add type checking built_ins `is_null`, `is_string`, `is_boolean` and `is_number`
- add type checking built_ins `is_enum`, `is_sequence`, `is_hash` and `is_range`

=== Bugfixes

- fix the error message on non-primitive results in switch/on and switch/case expressions
- fix missing `init` call, when manually register a `TemplateFeatureProvider`
- always process exceptions for slice errors

== Release 1.8.0 (2025-04-20)

=== Improvements

- add `easter` built-ins for temporal types with a year part

=== Experimental

- add new Extension API

=== Deprecations

- deprecate Plug-In Mechanism

== Release 1.7.5 (2025-03-21)

=== Improvements

- add full `java.util.Locale` support
- add `country_name` and `language_name` built-ins for `java.util.Locale`
- add `compress` user directive
- add `compress` and `oneliner` as standard user directives

== Release 1.7.4 (2025-03-03)

=== Improvements

- add `java.util.Optional` support

== Release 1.7.3 (2025-02-20)

=== Bugfixes

- the greater `>` and the greater equals `>=` operator must be surrounded by  parenthesis in directive expression to distinguish it from the directive closing symbol `>`. Accidentally the `≥` operator too.
- fix template reduction for conditional directives

== Release 1.7.2 (2025-02-11)

=== Improvements

- add `offset` part to the list directive
- add `+` list concatenation operator
- add `+`, `-` year operator

== Release 1.7.1 (2025-01-25)

=== Improvements

- add `empty_to_null`, `blank_to_null` and `trim_to_null` built-ins

=== Experimental

=== Breaking Changes

== Release 1.7.0 (2025-01-17)

=== Improvements

- support for `java.time.Year`, `java.time.YearMonth` and `java.time.MonthDay`
- add `is_leap` built-in for `java.time.Year` and `java.time.YearMonth`
- add `year` built-in for `java.time.Year`, `java.time.YearMonth`, `java.time.LocalDate` and `java.time.LocalDateTime`
- add `month` built-ins for `java.time.YearMonth`, `java.time.MonthDay`, `java.time.LocalDate` and `java.time.LocalDateTime`
- add `day` built-in for `java.time.MonthDay`, `java.time.LocalDate` and `java.time.LocalDateTime`
- add `long`, `full`, `medium` and `short` formats.
